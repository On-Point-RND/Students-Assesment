# Baseline

## Description
baseline.py - script for llm-as-a-judge with one prompt and structured output, save csv file with columns "llm_analysis" and "llm_score"(using openai api)


baseline.ipynb - example with run script and check results.

## Instruction
1. Install packages from requirements.txt
2. Create .env with OPENAI_API_KEY, BASE_URL and MODEL
3. run script baseline.py
